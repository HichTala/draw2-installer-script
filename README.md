# Draw2 — YuGiOh Card Detector for OBS
 
Plugin for OBS that detects YuGiOh cards in real time. Download the installer from the [DRAW2 plugin page](https://github.com/HichTala/draw2-plugin).
 
## ⚠️ Windows Defender warning
 
Windows may flag the installer as malware, this is a **false positive**. The `.exe` is built with PyInstaller, which bundles Python apps into executables that antivirus tools often flag as suspicious. There is no code signing certificate, which triggers the SmartScreen warning.
 
The full source code is right here in this repo if you want to verify it yourself. To bypass the warning, click **"More info" → "Run anyway"**.
